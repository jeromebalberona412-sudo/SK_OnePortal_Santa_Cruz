## Status Options (All Programs)

- **Pending** - Application submitted, awaiting review
- **Approved** - Application approved, participant confirmed
- **Rejected** - Application rejected
- **Pending Payout** - Approved but payment/benefit pending
- **Paid/Completed** - Benefit provided or program completed
- **Cancelled** - Participation cancelled

## Common Application Fields (All Programs)

1. **Personal Information**
   - Last Name
   - First Name
   - Middle Name
   - Date of Birth
   - Gender
   - Age (auto-calculated)
   - Contact Number
   - Complete Address
   - Email Address

2. **Program-Specific Information**
   - (Varies by program type - see custom_fields above)

3. **Requirements**
   - Valid ID (Front & Back)
   - Barangay Certificate
   - Medical Certificate (if applicable)
   - Parental Consent (for minors)
   - Other documents (program-specific)

4. **Signature**
   - Digital signature or printed name
